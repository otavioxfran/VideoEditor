# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso(a), acolha quem está começando (inclusive quem não é da área
de computação), critique ideias e não pessoas, e não tolere assédio de nenhum tipo.

## Como reportar

Comportamentos inaceitáveis podem ser reportados de forma privada pela aba
[Security](../../security/advisories/new) do repositório ou diretamente à pessoa mantenedora
pelo GitHub ([@otavioxfran](https://github.com/otavioxfran)). Todas as denúncias são
tratadas com sigilo.
